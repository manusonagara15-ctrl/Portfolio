# Maheshvaree Sonagara — Portfolio

This repository contains the source code for my personal portfolio website.

## Files
- `index.html` — complete responsive portfolio website (HTML, CSS, JavaScript, and embedded portrait).
- `README.md` — project information and deployment notes.

## Deploy on Vercel
This is a static HTML project. No framework or build command is required. In Vercel, select **Other** as the framework preset and use the project root containing `index.html`.
